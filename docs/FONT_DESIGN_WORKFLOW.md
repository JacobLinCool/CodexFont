# 字體設計流程

這套流程把一個字體想法做成可發布的字型。完整操作規則在
[`design-font-family` skill](../.agents/skills/design-font-family/SKILL.md)。

開始前，先說清楚：

- 字體用在哪裡、給誰看；
- 要支援哪些文字；
- 希望有什麼感覺；
- 哪些例句最重要；
- 要用什麼授權。

接著：

1. 先做少量代表字，確定筆畫、比例與間距。
2. 固定完整字集和字序，不在途中猜字。
3. 用圖片生成工具寫出新的白底黑字原稿。
4. 參考字體只用來認字，不取用它的輪廓。
5. 逐字檢查錯字、缺筆、碎墨、格線和小尺寸可讀性。
6. 把通過的原稿轉成向量，再檢查尖刺、重疊與裁切。
7. 人工查看黑底白字、白底黑字、短句、長文和直排。
8. 只用已核准的字形建置 TTF、OTF、WOFF 和 WOFF2。
9. 建置兩次；結果必須相同。
10. 在真實瀏覽器試寫、找缺字，再發布。

每一步都記錄字集、原稿、review、approval 與雜湊。只要其中一項改變，就重新
檢查。缺字不能用 fallback 假裝成已完成。
